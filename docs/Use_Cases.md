# Document preparation use cases this course must cover

Plan lessons around the documents S2P professionals actually produce. Every use case below should get its own lesson, built using the six-part structure in `CLAUDE.md` and `Lesson_Template.md`.

| Document | Typical S2P role | Lesson focus |
|---|---|---|
| RFI / RFP / RFQ | Sourcing manager | Generate, update scope, refresh supplier list, build evaluation matrix |
| NDA and MSA drafts | Contract manager | Pull clauses from a clause library, redline against a counterparty version |
| Supplier scorecard | Category manager | Build from KPI data in Excel, add commentary, export to PDF |
| Savings tracker report | Procurement analyst | Pivot raw spend, compute realised vs planned savings, write the narrative |
| Supplier onboarding pack | P2P operations | Compile NDA, code of conduct, bank details form, W-8/W-9 into one PDF |
| Category strategy deck | Category lead | Convert a Word brief into a structured PowerPoint outline |
| Risk and compliance memo | Risk manager | Summarise news on a supplier, flag sanctions and ESG concerns, draft memo |
| AP exception report | AP lead | Read invoice exceptions export, group by reason, draft email to requesters |
| Contract renewal brief | Contract admin | Read the live contract, list dates, prices, and auto-renewal clauses, draft brief |
| Tender clarification log | Sourcing manager | Merge supplier questions from email, deduplicate, draft consolidated answers |

When a lesson covers a document type, name the document type in the lesson title. Example: "Lesson 4: Build a supplier scorecard from an Excel KPI export".
